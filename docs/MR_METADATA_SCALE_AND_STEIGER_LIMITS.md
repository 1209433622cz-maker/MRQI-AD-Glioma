# EDA86 MR来源、方差列尺度与Steiger补充解释

本轮使用已知结果的固定10/57工具作诊断再分析，不是新暴露选择或预注册。原效应、原R2字段与历史文件不覆盖。

1. 67工具的EUR rsID/allele-set全部匹配；570跨方向组合全量估计。没有exact交集，也没有预定r²≥0.8对。最大r²=0.775069（rs75061358—rs74504435，参考距离32976bp），因此不能写成两套工具完全无局部关联；本轮不因结果接近阈值而更改阈值或删SNP。
2. PLINK与独立BED解码570对按PLINK文本精度核对；空剔除集只重复同一估计器，不是新的独立复制。12项原β/SE/P复算误差≤1e-12。
3. 57个AD工具的自身raw均找到n_cases、n_controls及EAF，出现6组精确样本数，不能将487511统一赋给所有SNP。两个raw文件完整SHA与旧冻结一致，114条源效应/频率连接均核对。
4. 新发现：Liu补表12个GBM行标为R2的数值全部在5e-10内符合sqrt(F/(F+N−2))，而非F/(F+N−2)。例如rs10069690原值0.116536704、其平方约0.013580803。这里只识别数值尺度不一致，不自行修改作者表或原项目输入，也不将此t/N近似称二分类liability R²。主MR只用β/SE，当前核对未改变主估计。
5. EDA87已追溯Liu Table 1声明6183病例／18169对照＝24352；原Melin总体6191+18190=24381的版本差及exact研究EAF仍未闭合。不能将“已找到声明”写成“原始分析人群与每SNP频率均已验证”。反向AD含proxy病例，病例计数已闭合仍不等于strict AD prevalence含义闭合。正式liability Steiger及其prevalence/测量误差敏感性继续SOURCE/PHENOTYPE HOLD，本轮没有伪造Steiger P或通过状态。

这解决了exact/LD诊断及反向逐SNP字段提取，并新增一个会影响方差解释的具体审计发现；不证明排除限制、方向因果或当前81/43的靶点机制。下一步可先用公开原始方法/更正材料闭合该R2列语义与GBM样本/EAF来源；无新来源时保留遗传背景的限定，不绕过受控访问或升级因果结论。
