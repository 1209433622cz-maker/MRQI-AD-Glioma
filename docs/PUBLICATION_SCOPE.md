# 公开范围与内容审查

公开内容为项目生成的基因级汇总、完整81／43表、模型实现快照、9幅汇总图及新写的研究说明。它不是整个H盘的备份。所有发布路径均由显式allowlist生成；没有对canonical根目录执行git add。

不公开raw／participant-level数据、逐人删除明细、完整空间患者行、受控文件及受限制衍生物、DUC／身份／签署申请、认证缓存／令牌、第三方PDF及运行环境副本。S08c与S10a仅去除patient_ids列；未删除基因、方向、P/q、冲突或缺失。完整本地原表未修改。

PUBLIC_MANIFEST记录所有公开资产但不包含自身。PUBLIC_ASSET_PROVENANCE记录原文件hash、发布hash和列删除。公开包的自动扫描不是无限范围的隐私或机构合规认证；受控数据以后也不得直接加入Git历史。发现潜在敏感问题时请联系仓库所有者，避免在公开Issue中粘贴个人或受控数据。
